## feature_id space



推荐平台的feature_id space 的理解？ 咨询chatgpt：https://chatgpt.com/c/69b7be9e-c338-8323-aefd-6e4f531021ed

feature_id space 不是特征个数，是特征取值的总数。

比如：我有两个特征： 爱好和性别， 爱好取值：20个  性别取值：2 个  那么我的feature_id space是20+2=22.
也就是我的token 总数是22个。 

| 术语               | 含义       |
|------------------|----------|
| feature          | 字段       |
| feature value    | token    |
| feature_id       | token 编号 |
| feature_id space | token总数  |


feature_id -> embedding vector
embedding table：[100亿 , 64]
表的大小： 10B × 64 × 4 byte ≈ 2.5 TB


这张表这么大，我该怎么处理？高效的支持推荐系统模型的训推。
