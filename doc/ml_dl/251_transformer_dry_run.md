#### 1.1.2 inference-block1-15-Gelu ： 为什么用gelu这个非线性变换？

* 近似GELU
  \[
\boxed{
\operatorname{GELU}(u)
=
\frac{1}{2}u\left(1+\tanh\left(\sqrt{\frac{2}{\pi}}\left(u+0.044715u^3\right)\right)\right)
}
\]
注意：GPT-2 用的是这个 **tanh 近似版 GELU**，不是精确的 \(\operatorname{GELU}(x)=x\Phi(x)\) 形式。

* 数学原理：用高斯概率来“加权”
   GELU 的核心公式完美体现了上述思想：
   GELU(x) = x · Φ(x)
   
   这里的 Φ(x) 是标准正态分布的累积分布函数 (CDF)，它的值域在 0 到 1 之间。可以把 Φ(x) 直观地理解为：“一个服从标准正态分布的随机变量，其值小于等于当前输入 x 的概率”。
   
   因此，GELU 的作用就是用一个由 x 自身大小决定的概率值 Φ(x)，去给输入 x 加权：
   
   当 x 很大（正数） 时，Φ(x) 无限趋近于 1，输出几乎就是 x 本身。
   
   当 x 很小（负数） 时，Φ(x) 无限趋近于 0，输出被平滑地抑制到接近 0。
   
   在 x 接近 0 的区域，进行平滑的过渡，而非突变。这也允许极小的负值通过，并在 x 约为 -0.75 时产生一个微弱的负输出（最小值约 -0.17）。
   
   在实际计算中，由于精确的 Φ(x)（涉及 erf 函数）较慢，框架通常采用基于 tanh 的快速近似公式，以在保持效果的同时提升效率。
* GELU 的设计动机，直接对应着它想要解决的几个问题：

  1. 根本目的：确保“有效”的非线性，防止模型退化
这是激活函数存在的根本理由。如果 MLP 中没有非线性激活函数，两个线性层 W₁ 和 W₂ 在数学上会坍缩成一个单一的线性映射 W₂W₁，模型将失去学习复杂模式的能力。GELU 的首要任务就是打破这种线性坍缩，为网络注入真正的非线性表达能力。
  1. 核心改进：用“平滑性”替代 ReLU 的“硬伤”
这是 GELU 区别于 ReLU 的关键，也是它被设计出来的直接原因。
     * 消除“死亡神经元”：由于 GELU 在负区间也保留了微小但非零的梯度，那些“暂时被抑制”的神经元仍有被重新激活的可能，避免了永久死亡。
     * 提供更“干净”的梯度：GELU 处处连续可微，没有 ReLU 在零点处的尖角。这在反向传播时能为优化器提供更平滑、更稳定的梯度信息，有助于深层网络的训练收敛。
  1. 附加收益：内置的“自适应正则化”
GELU 的概率性加权机制本身构成了一种依赖于输入的正则化。它在训练中动态地抑制那些“置信度低”的信号，这种效果类似于一种更智能的自适应 Dropout，有助于提升模型的泛化能力，防止过拟合。

### 1.2 OUPUT

#### 1.2.1 OUTPU-34-Temperature ： 了解温度系数的功能呢？

在 softmax 之前，logits 会被除以一个温度 \(\tau\)。Softmax 只依赖于 logits 之间的差值，而除以 \(\tau\) 会把每个差值缩放为原来的 \(1/\tau\)：

- \(\tau<1\)：放大差距，分布更尖锐、更确定；
- \(\tau>1\)：缩小差距，分布更平坦、更随机；
- \(\tau\to 0\)：趋近于贪心 argmax；
- \(\tau=1\)：保持模型学到的原始分布不变。

1. OUTPUT-36-Sample： 了解下怎么采样的？

* 常用的下一个token的解码策略，常用的有三种：
  Greedy Sample TopK TopP
* sample/topk/topp策略中：u不知道怎么算的？

  \[
  \text{PRNG(seed=42) 的第 5 个输出} \rightarrow 0.4345\]
  含义是：
- **seed 42**：伪随机数生成器的种子设为 42；
- **position 5**：取该 PRNG 序列中的第 5 个随机数；
- 这个随机数被归一化到 \([0,1)\) 区间，得到 **\(u=0.4345\)**

所以 \(u\) 的来源是：

它和 token 的概率 \(p_v\) 无关，只用于**采样定位**：把候选 token 的概率首尾相接铺在 \([0,1)\) 上，然后看 \(u=0.4345\) 落在哪一段，就选哪个 token。

例如若候选 token 的累积概率区间是：

\[
[0,0.2),\ [0.2,0.55),\ [0.55,0.8),\dots
\]

那么：

\[
u=0.4345 \in [0.2,0.55)
\]

所以会选第二个 token。

如果是 **top-k 或 top-p**，流程是：先过滤候选 token，再重新归一化，然后把新的累积概率铺在 \([0,1)\) 上，最后仍然用这个 \(u=0.4345\) 去定位。也就是说：

- **概率分布决定“区间怎么划分”**；
- **\(u\) 决定“随机落在哪个区间”**；
- **seed 和 position 决定 \(u\) 可复现**：同样的 seed=42、position=5，就会得到同样的 \(0.4345\)。

因此，\(u=0.4345\) 是**伪随机采样数**，不是模型 logits，也不是 softmax 概率；它是“抽签用的随机坐标”。



## 二、 pretraining 训练

### 2.1 DATA & INITIALISATION

#### 损失函数

gpt2使用的损失函数是：**语言模型训练的交叉熵损失函数**，更准确地说，是**平均负对数似然损失**：

\[
L=\frac{1}{6}\sum_{i=0}^{5}-\log p(t_{i+1}\mid t_0,\dots,t_i)
\]

含义是：

- 对每个位置 \(i\)，模型在只看到 \(t_0,\dots,t_i\) 的条件下，预测下一个 token \(t_{i+1}\)；
- \(p(t_{i+1}\mid t_0,\dots,t_i)\) 是模型给正确下一个 token 的概率；
- 取负对数 \(-\log p\)，正确 token 概率越高，损失越小；
- 最后对所有位置求平均：token的个数是7个，N=6 求平均

**为什么？损失函数只考虑计算了预测正确情况下损失，对于预测错误没有考虑**

交叉熵是：

\[
L_i
=-\sum_{v\in\mathcal V} q_i(v)\log p_\theta(v\mid \text{context})
\]

逐项看：

- 对正确 token \(v=t_{i+1}\)：\(q_i(v)=1\)，这一项是  
  \[
  -1\cdot \log p_\theta(t_{i+1}\mid \text{context})
  \]
- 对错误 token \(v\ne t_{i+1}\)：\(q_i(v)=0\)，这一项是  
  \[
  -0\cdot \log p_\theta(v\mid \text{context})=0
  \]



核心原因就一句话：所有 token 的概率加起来必须等于 1，所以错误 token 的概率变高，虽然没有计入到损失，但正确 token 的概率肯定会被压低，所以变相的已经增加了损失。
